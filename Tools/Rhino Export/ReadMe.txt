For compiling this project, %RhinoSDKPath% environment variable must be defined (e.g. 'C:\Program Files\Rhino 4.0 SDK').


-This plugin works with 'Rhino 4.0 SDK'.
-To build you should have installed 'Rhino 4.0 SDK'
-In the file LaunchDevenv.bat, please update the env variable, 
 'RhinoSDKPath' with your 'Rhino 4.0 SDK' path. (eg: 'C:\Program Files\Rhino 4.0 SDK' )
-Launch the VS2008 devenv using 'LaunchDevenv.bat'



It is necessary to register plug-in manually in Rhino environment
