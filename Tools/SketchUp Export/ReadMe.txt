For compiling this project, %SketchUpPath% environment variable must be defined 
in the LaunchDevenv.bat.

Use vs2008 devenv launched by 'LauchDevenv.bat' to compile the sketchup plugin.

(e.g. 'C:\Program Files\Google\Google SketchUp 7').

COM Autoregistration is disabled, because registration is performed during Post-build step

SketchUp SDK (COM interfaces) is placed in 'Interfaces' subfolder
